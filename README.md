# Кулинарная книга

Сайт с рецептами на [Hugo](https://gohugo.io), бесплатно размещается на GitHub Pages.

```
content/recipes/      ← рецепты, по одному .md-файлу на блюдо
static/images/        ← фотографии (папку создайте сами, когда понадобится)
static/css/style.css  ← оформление
layouts/              ← шаблоны страниц
archetypes/recipes.md ← заготовка для нового рецепта
hugo.toml             ← настройки сайта (название, меню)
```

---

## 1. Опубликовать сайт (один раз)

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Создайте новый репозиторий (**New repository**):
   - назовите его `ВАШ-ЛОГИН.github.io`, и сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/`;
   - или любым другим именем, например `kulinar`, и сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/kulinar/`.
   - Видимость: **Public** (для бесплатного Pages).
3. Загрузите в репозиторий все файлы из этой папки:
   - самый простой способ: [GitHub Desktop](https://desktop.github.com): *File → Add local repository* → выбрать эту папку → *Publish repository*;
   - или через командную строку:
     ```
     git init
     git add .
     git commit -m "Первая версия сайта"
     git branch -M main
     git remote add origin https://github.com/ВАШ-ЛОГИН/ИМЯ-РЕПОЗИТОРИЯ.git
     git push -u origin main
     ```
4. Добавьте автопубликацию: на странице репозитория нажмите **Add file → Create new file**,
   в поле имени впишите ровно `.github/workflows/hugo.yml` (слэши сами создадут папки),
   вставьте содержимое файла `hugo-workflow.yml` из этой папки и нажмите **Commit changes**.
   Файл `hugo-workflow.yml` после этого можно удалить из репозитория.
5. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
6. Откройте вкладку **Actions**: через 1–2 минуты сборка станет зелёной, и сайт откроется по адресу выше.
   Если сборка запустилась до шага 5 и упала, нажмите на ней **Re-run all jobs**.

Дальше каждое изменение, отправленное в ветку `main`, публикуется автоматически.

## 2. Добавить рецепт

Скопируйте любой файл из `content/recipes/` и переименуйте его латиницей через дефис
(например, `borsch.md`, тогда адрес будет `/recipes/borsch/`). Затем поменяйте содержимое:

```yaml
---
title: "Борщ"
description: "Одно предложение о блюде."
date: 2026-10-10
emoji: "🥣"                 # картинка, пока нет фото
# image: "/images/borsch.jpg" # фото положите в static/images/
categories: ["Супы"]
tags: ["свёкла", "говядина"]
servings: 6
time: "2 ч"
difficulty: "Средне"
ingredients:
  - items:                   # группа без названия
      - "500 г говядины на кости"
  - group: "Зажарка"         # группа с подзаголовком
    items:
      - "1 свёкла"
---

1. **Шаг первый.** Текст.

2. **Шаг второй.** Текст.

> **Совет:** необязательная подсказка в рамке.
```

Важно: в начале и конце блока настроек стоят три дефиса `---`, отступы в списке ингредиентов
сделаны **пробелами** (не табуляцией), каждый ингредиент заключён в кавычки.

Если установлен Hugo, можно создать файл командой `hugo new recipes/borsch.md`.

## 3. Посмотреть сайт у себя до публикации (необязательно)

```
winget install Hugo.Hugo.Extended
hugo server
```

Затем откройте http://localhost:1313. Страница обновляется сама при сохранении файлов.

---

## 4. Подключить свой домен (необязательно)

1. Купите домен, например `.ru` у reg.ru, nic.ru или beget (примерно 200–400 ₽ в год).
2. В панели регистратора в настройках DNS добавьте записи:
   - для домена вида `www.moi-recepty.ru`: запись **CNAME** `www` → `ВАШ-ЛОГИН.github.io`;
   - для «голого» домена `moi-recepty.ru`: четыре записи **A** на
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
3. В GitHub: **Settings → Pages → Custom domain**, впишите домен и сохраните.
   Когда проверка DNS пройдёт (от нескольких минут до суток), включите **Enforce HTTPS**.
4. Пересоберите сайт: вкладка **Actions** → *Публикация сайта* → **Run workflow**.
