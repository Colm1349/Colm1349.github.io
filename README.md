# Кулинарная кНига

Сайт: https://colm1349.github.io/

Обычный HTML без сборки, GitHub Pages отдаёт файлы как есть.

| Файл | Что это |
|---|---|
| `index.html` | оформление и логика сайта (меню слева, страницы рецептов) |
| `recipes.js` | **все рецепты**: обычно редактируется только этот файл |
| `images/` | фотографии блюд (создайте папку, когда понадобится) |
| `.nojekyll` | служебный пустой файл, говорит GitHub «не обрабатывать сайт» |

## Как добавить рецепт

1. Откройте `recipes.js` в любом редакторе (Блокнот подойдёт, удобнее [VS Code](https://code.visualstudio.com)).
2. Скопируйте блок одного рецепта: от `{` до `},` включительно.
3. Вставьте его перед последней строкой `];` и поменяйте текст.
   `id` должен быть уникальным и написанным латиницей, например `borsch`.
4. Проверьте у себя: просто откройте `index.html` двойным щелчком.
5. В GitHub Desktop: **Commit to main → Push origin**. Через минуту изменения будут на сайте.

Частые ошибки: забытая запятая между рецептами, кавычка внутри текста
(используйте «ёлочки»), пропущенная скобка. Если меню опустело, значит, в `recipes.js` опечатка.

## Своё доменное имя

1. Купите домен, например `.ru` у reg.ru, nic.ru или beget.
2. В DNS добавьте четыре записи **A** на `185.199.108.153`, `185.199.109.153`,
   `185.199.110.153`, `185.199.111.153` (и/или **CNAME** `www` → `colm1349.github.io`).
3. В GitHub: **Settings → Pages → Custom domain**, затем включите **Enforce HTTPS**.
